# 向量召回修复：为什么纯文本比对是错的，以及改正后的数据（P0.9）

> 用户指出：绝大多数记忆系统用向量比对，我却用纯文本比对——这是玩太大了。
> 结论：**用户是对的。已改为"向量召回 + Jev 判定"，事实级数字也随之修正。**

## 1. 为什么会犯这个错

- 最初测 `POST https://opencode.ai/inference/go/openai/v1/embeddings` → **404**；
- 当时就下结论"没有 embeddings 可用"，退回"词面候选 + LLM 判定"；
- **没有再去查其他嵌入入口**——实际上 OpenRouter 现在提供 **42 个 embedding 模型**（bge-m3、qwen3-embedding-8b、voyage、gemini-embedding、OpenAI 3-small 等）。

这是查证不彻底，不是没有方案。

## 2. 词面 vs 向量的召回基准（190 条有效 claim，6 组已知同事实簇）

| 指标 | 词面（字符 2-gram） | qwen3-embedding-8b | bge-m3 |
|---|---|---|---|
| **整体 recall@10** | **41%** | **81%** | **84%** |
| 道歉簇（7 条） | **0%** | 57% | 57% |
| 董事会调查簇 | 70% | 100% | 100% |
| 中国否认簇 | 30% | 100% | 100% |
| 情报资产簇 | 90% | 90% | 100% |
| Megaspeed 调查簇 | 40% | 80% | 90% |
| 随机对相似度 p50 / p95 | — | 0.394 / 0.627 | 0.422 / 0.653 |

**道歉簇词面召回 0%** —— 正是用户抓到的那个 bug：C030/C043/C044/C051/C149/C175/C222 两两字符相似度只有 0.00–0.15。

## 3. 改正后的管线与数据

```
claim → embedding（bge-m3，1024 维）→ 每条约 top-8 近邻（sim ≥ 0.5）
      → Jev 判定"是否同一核心事实" → 并查集 → fact 簇
```

| 指标 | 数值 |
|---|---|
| 有效 claim | 190 |
| 向量候选对 | 1,028 |
| Jev 判定同事实 | 95 对 |
| **事实簇** | **134** |
| **事实级冗余** | **29.5%** |
| Story 引用 claim | 178 |
| Story 覆盖事实 | **127**（内部冗余 28.7%） |

**道歉簇已正确合并**：C030/C043/C051/C149/C175/C222 归为 1 个事实簇（6 条 claim）。
最大的簇：董事会调查 12 条、情报资产 9 条、中国否认 7 条、道歉 6 条、Megaspeed 调查 5 条。

与另一条独立方法（顺序判新：190→130 事实）互相印证：**130 vs 134**，两个方法收敛在同一水平。

## 4. 修正后的完整指标链

| 口径 | 冗余率/事实数 |
|---|---|
| 原始 claim | 247 |
| 剔除噪声 + 严格字面去重 | 190 |
| **事实簇（向量召回 + Jev）** | **134** |
| **事实级冗余** | **29.5%** |
| 顺序判新（独立验证） | 130 事实 / 31.6% |
| 留一源跨源覆盖 | 41.6% |

**5% 是词面口径的假象；真实冗余是 30% 量级，三个独立方法给出一致的量级。**

## 5. 成本与容量（可扩展到百万级）

| 项 | 单价 | 1,000 claims | 1,000,000 claims |
|---|---|---|---|
| Embedding（bge-m3） | $0.01 / 1M tokens | ~$0.0005 | ~$10 |
| 向量存储（int8 量化 1024 维） | — | ~1 MB | ~1 GB |
| Jev 判定（top-8 候选，约 4,000 对/千条） | $0.042 / 1M tokens | ~$0.03 | ~$30 |
| 合计 | — | ~$0.03 | **~$40** |

结论：向量召回在成本上完全可行，没有理由用词面替代。

## 6. 架构修正（写入 DECISIONS）

1. **候选生成必须用向量**：embedding 存 `claim.embedding`（int8 量化），近邻检索 top-k（k=8~10，阈值 0.5）；
2. **词面只作补充路**：精确重复、数字/编号命中用词面/FTS，不再承担语义召回；
3. **Jev 负责精度**：对向量候选做"同事实"判定，输出 `fact_id`；
4. **抽取时就归簇**：新 claim → embedding → 近邻 → Jev → 命中挂已有 `fact_id`，否则新建；
5. **Story 引用事实簇**，claim 作为事实的出处实例。

## 7. 复现

```bash
node 49_vector_dedupe.mjs        # 向量 vs 词面召回基准
node 50_vector_fact_cluster.mjs  # 向量召回 + Jev → 事实簇（134）
```
