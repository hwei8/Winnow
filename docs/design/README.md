|---|---|
| `DESIGN-PROPOSAL.md` | 最初的产品与技术方案（双形态、预算、结构化程度） |
| `DECISIONS.md` | 决策台账 D1–D53，每条含背景、选择、被否决的替代方案 |
| `SCHEMA-DRAFT.md` | 早期 schema 草案（现以 `src/shared/schema.mjs` 为准） |

| `AUDIT-FINAL.md` | 阶段验收（P0–P4 完成度与缺口） |
| `STATUS.md` | 路线图与当前状态 |

新的架构决策请写进 `docs/adr/`（编号递增），不要继续追加到 `DECISIONS.md`。
