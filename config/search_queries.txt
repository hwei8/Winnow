# 语法（对齐 TrendRadar 的 search_queries）：
#   [主题名]        段落第一行，给这组搜索起名
#   !排除词         标题/摘要含该词的结果丢弃
#   -site:域名      屏蔽站点（全局区可用）
#   site:域名       只看该站点
#   @数字           本主题最多入库几条
#   ~数字d          只看最近 N 天（~0d = 不限）
#   @provider:名称  预留给多引擎，目前只支持 deepseek
#
